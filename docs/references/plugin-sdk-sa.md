## Değerlendirme sonucu

ADR-35 ile Dryxio fork'u **D1 için seçilmiş native erişim adayı**dır. İlk tercih sürümü sabitlenmiş, asgari dosya kümesiyle private build entegrasyonudur. Kaynak/build veya hook lifecycle kapısı geçmezse engel raporlanır; aynı görevi doğrulanmış dar SAEX binding'iyle karşılamak ya da upstream sürümü seçmek yeni kanıt ve ADR güncellemesi ister. Güncel branch'i otomatik takip etmek veya çalışan mod örneğini doğrudan platform bootstrap'ına taşımak kabul edilmiş yöntem değildir.

## N2 executable gözlemi — 13 Eylül 2026

Pinned GameVersion.cpp'deki Hoodlum marker adayı ile Events.h'deki gameProcess/initGame/shutdownRw call adresleri yerel dosyada kısa byte kontrolüyle karşılaştırıldı. Dört anchor ve göreli disk hedefi [N2 raporuna](../development/d1-engine-preflight.md) ve observation-only JSON'a kaydedildi; tam dosya hash'i eşleşmeden marker kabulü yoktur. Çalıştırılmayan Windows image görünümü de eşleşti. Function ABI, unpack fazı, callback güvenliği ve init/frame/stop runtime kanıtı bu gözlemden çıkmaz. Bu kaynaklar inceleme girdisidir; N1'in derlenen 23 SDK dosyası veya recipe'si genişletilmedi.
