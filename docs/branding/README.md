# SAEX marka varlıkları

Marka **SAEX**, açılım **San Andreas Extended**. [Vektör işaret](saex-mark.svg) organizasyon avatarının, [banner](saex-banner.svg) README girişinin kaynağıdır. Her ikisi bu proje için geometrik şekiller ve sistem yazı tipiyle üretildi; üçüncü taraf logo veya GTA görseli içermez.

Koyu zemin `#101b22`, vurgu `#b8f36d`, açık metin `#f0f5ef`. Küçük ölçekte işaret, geniş alanda SAEX açılımı kullanılır. Ürün sloganı: **Kendi dünyanı ve oyun deneyimini geliştir.**

Bu görseller [MIT](../../LICENSE) kapsamındaki proje kaynaklarıdır. GitHub avatarı için vektörden türetilen PNG kullanılır. Marka veya görsel, multiplayer'ın tamamlandığı veya Rockstar tarafından onaylandığı iddiası taşımaz.
